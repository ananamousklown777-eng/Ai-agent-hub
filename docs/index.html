Breeze Live

An experimental AI host for audience chat, voice interaction, and an animated avatar.

What it does

Breeze Live combines a chat room, AI-generated replies, browser-supported voice input and playback, and an animated avatar session. A simulation mode can send sample audience messages for testing.

How it works

Visitors can enter a display name and send a message. The AI backend generates a reply, and the avatar session can speak it when available. Voice features depend on browser and device support.

Current limitations

This is a prototype, not an official TikTok product and not affiliated with or endorsed by TikTok. The current build supports chat simulation and a TikTok authorization flow, but it does not yet provide a verified direct feed of real TikTok LIVE comments. Connecting a TikTok account does not by itself enable LIVE chat access.

Privacy and terms

Chat state is currently held in server memory and may not persist after a restart. Depending on features used, information may be processed by AI, avatar, hosting, browser, and third-party providers. Do not submit sensitive or confidential information.
