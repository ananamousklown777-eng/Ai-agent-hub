Breeze Web Agent

Give a public webpage to Breeze. It opens the page, summarizes its basic content, collects useful links, and takes a screenshot. One small step toward a reusable browser tool, not a magic robot army.

For public pages only. Local/private network addresses are blocked. Do not enter passwords, private account pages, or sensitive information. Limited to five runs per IP per ten minutes in this prototype.
